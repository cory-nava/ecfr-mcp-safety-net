# Golden eval results, 2026-10-27: best tier on a local LLM (Gemma 4 12B, LM Studio)

Same frozen 50 queries (`eval.json`), shipped `data/` (bge-small), shipped code on branch
`local-llm-lmstudio`. Only the LLM differs: HyDE and the listwise rerank both run on
`google/gemma-4-12b` in LM Studio, thinking off (`reasoning_effort: "none"`).

- Machine: Apple M4 Pro, 24 GB. LM Studio loaded with `-c 16384 --parallel 1`.
- Requests: one at a time (HyDE, then 5 rerank batches of 10 chunks in series).
- Measured through the server's own retrieval code, so the citation fast-path is included.

Reproduce:

```bash
lms load google/gemma-4-12b -c 16384 --parallel 1
ECFR_MCP_LLM_URL=http://localhost:1234/v1 python golden/eval_server.py --tier best
```

## Result

```
tier=best model=BAAI/bge-small-en-v1.5 eval=eval n=50 degraded=0
overall     r@1=0.84  r@3=0.94  r@5=0.94
exact       r@1=1.00  r@3=1.00  r@5=1.00  (n=5)
natural     r@1=0.91  r@3=0.97  r@5=0.97  (n=33)
paraphrase  r@1=0.58  r@3=0.83  r@5=0.83  (n=12)
```

0 of 50 queries degraded to the free tier. The 45 queries that reached the LLM averaged
102s each (77 minutes in total); the 5 exact citations return instantly.

## Against the other tiers

| Config | r@1 | r@3 | r@5 | Time / query | Cost / query |
|---|---|---|---|---|---|
| Free tier (citation fast-path + vectors) | 0.60 | 0.78 | 0.80 | <1s | $0 |
| HyDE + flash-lite (OpenRouter) | 0.76 | 0.92 | 0.94 | ~2s | ~$0.002 |
| HyDE + gpt-6-luna (OpenRouter, best-tier default) | 0.82 | 0.98 | 0.98 | ~35s | ~$0.002 |
| **HyDE + Gemma 4 12B, local, thinking off** | **0.84** | 0.94 | 0.94 | ~102s | $0 |

## Reading it

- **r@1 matches Luna.** 0.84 vs 0.82 is one query at n=50, well inside the ±0.09 CI.
- **r@3/r@5 trail Luna by 2 queries** (0.94 vs 0.98): the misses that Gemma doesn't put in the
  top 5 at all, Luna does.
- **The gap is paraphrase.** Natural queries are 0.91 r@1; paraphrases are 0.58 (7 of 12).
  Luna's paraphrase r@1 is recorded as 0.75. Thinking off is the obvious suspect: Luna's
  edge over flash-lite was attributed to its chain-of-thought (2026-10-17).
- **Speed is the real cost.** ~102s per query, almost all prompt reading (~20k tokens a query).
  Fine for a batch job or a patient agent; slow for interactive use.
